ddi-xlsx 코드북 검사실
직접 실행설치와 예시 코드WASM 불러오는 중

코드북을 검사하고,
같은 API를 코드로 실행하세요.

파일을 고르거나 예시로 시작하세요. 기존 Go 엔진을 WASM으로 실행합니다.
기본 검사와 변환은 브라우저 안에서 처리하며, 검사 API 서버를 호출하지 않습니다.

입력 파일

아직 선택하지 않음

문서 읽기와 지원하는 ID·변수·파일 참조를 검사합니다. XSD는 실행하지 않습니다.

예시로 시작하기

JavaScript REPL

입력은 input, 라이브러리는 api입니다. return한 값과 console.log를 출력합니다.

⌘ / Ctrl + Enter

초기화하면 실행을 멈추고 WASM과 state를 새로 만듭니다.

실행 결과

WASM을 준비하고 있습니다.

발견 항목

R은 반려 항목, W는 경고입니다. 발견 항목이 없어도 미실행 검사는 통과로 보지 않습니다.

REPL 출력
아직 실행하지 않았습니다.

무엇을 검사하나요?

일반 DDI와 재단 양식은 별도 경로로 읽습니다. 재단 양식에는 S05와 현재 엔진의 코드북 규칙을 적용합니다. XML 참조 검사는 엔진이 지원하는 ID·변수·파일 참조 범위입니다.

재코딩 이력은 형식과 참조를 검사합니다. 변환 실행·영향 건수 재현, 응답 CSV 교차검사·외부 코드표·NEIS 조회·XSD 검사는 실행하지 않습니다. 최종 제출 가능 여부는 별도 확인이 필요합니다.

설치와 예시 코드

현재 체크아웃에서 빌드합니다. npm 레지스트리 배포본이 아닙니다.

검사·변환 함수는 REPL 밖에서도 같은 방식으로 호출합니다. 각 예시를 실행 코드에 넣어 수정할 수 있습니다.

서버 없이 이 페이지 만들기

Go 1.25 이상과 Node.js 18 이상이 필요합니다. 레포 루트에서 실행하세요.

node demo/build.mjs

demo/dist/index.html을 브라우저에서 여세요. WASM·Go 로더·라이브러리·작업 스레드를 한 HTML에 담습니다. 정적 호스팅에서도 같은 파일을 사용할 수 있습니다.

Go 설치 안내

내 JavaScript 프로젝트에서 사용하기

npm install /path/to/ddi-xlsx/npm
import { checkCodebook } from 'ddi-xlsx';

const input = new Uint8Array(await file.arrayBuffer());
const report = await checkCodebook(input, {
  format: 'kosac-xlsx',
});
console.log(report.issues);

먼저 위 빌드로 npm 폴더의 WASM과 로더를 생성하세요. 일반 앱에서는 WASM과 로더를 함께 배포하고, 큰 파일은 Web Worker에서 처리하세요.

검사 API

return await api.checkCodebook(input, { format });

format: ddi, ddi-xlsx, kosac-xlsx. 문서 오류는 issues에 반환합니다. 지원하지 않는 인자는 오류로 거부합니다.

재단 v4 입력 규칙

TRANSFORM_TYPE은 필수 자유 입력입니다. 이 데모에는 승인된 변환 유형 목록을 공급하지 않습니다.

05 이력의 STATUS는 미착수·확인 필요·규칙 확정·처리 완료·검증 완료·적용 제외를 받습니다. 03·04의 RECODE_STATUS는 처리 완료·확인 필요 두 값으로 검사합니다.

코드북 수정·추가 매핑·대상 없는 검토 이력은 원문대로 읽고 별도 확인 항목을 경고로 표시합니다. 일반 데이터 변환의 실제 변수·파일 참조는 계속 검사합니다. 이력의 실행·재현과 최종 제출 상태는 별도 확인이 필요합니다.

DDI → 일반 편집용 Excel

const { xlsx, warnings } = await api.ddiToXlsx(input);
download('codebook.xlsx', xlsx);
return { bytes: xlsx.length, warnings };

먼저 DDI XML·JSON 예시를 선택하세요. 이 Excel은 재단 v4 양식과 다릅니다.

일반 편집용 Excel → DDI

const result = await api.xlsxToDdi(input);
download('codebook.xml', result.xml, 'application/xml');
return result.warnings;

먼저 일반 편집용 Excel을 선택하세요. download는 이 REPL의 보조 함수입니다. 실행 뒤 표시되는 파일 받기 버튼을 누르세요.

CLI와 Go에서 재단 양식 검사하기

go build -o dist/ddi-xlsx ./cmd/ddi-xlsx
./dist/ddi-xlsx kosac-check codebook.xlsx
cb, issues, err := template.Read(data, template.ReadOptions{})
if err != nil { return err }
if cb != nil {
    issues = append(issues, check.Check(cb, kosac.RefData{})...)
}

Go 패키지: github.com/teamPaprika/ddi-xlsx/kosac/template, kosac/check, kosac. XSD 검사는 CLI에서 xmllint를 공급하는 별도 단계입니다.

REPL에서 사용할 수 있는 값

api: 패키지 API / input: 선택한 파일의 Uint8Array / format: 선택한 형식 / examples.valid·examples.broken: 합성 XML / state: 실행 사이에 유지하는 객체 / console: 출력 / download(name, data, mime): 결과 파일 받기 준비.

예: state.report = await api.checkCodebook(input, { format }); return state.report;
