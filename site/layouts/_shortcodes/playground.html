엔진을 불러오는 중입니다. 처음 열 때 약 13 MB를 받습니다.

이 탭에서 JavaScript 코드로 SDK 함수를 호출합니다. 코드에서 아래 값을 씁니다.

  • api: SDK 함수
  • input: 입력 파일의 바이트(Uint8Array)
  • format: 입력 종류(ddi, ddi-xlsx, kosac-xlsx)
  • examples: 예시 XML 문자열(valid, broken)
  • state: 실행 사이에 값을 유지하는 객체
  • console.log: 출력에 한 줄을 씁니다.
  • download(name, data): 받기 버튼을 만듭니다.

코드가 return한 값은 출력의 맨 아래에 나옵니다.
